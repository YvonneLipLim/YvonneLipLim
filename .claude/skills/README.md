# Obsidian Skills

Agent Skills for working with Obsidian vault files, vendored from
[kepano/obsidian-skills](https://github.com/kepano/obsidian-skills) (MIT, by Steph Ango).

These are auto-discovered by Claude Code from `.claude/skills/`. Available skills:

| Skill | Use for |
|-------|---------|
| `obsidian-markdown` | Obsidian Flavored Markdown: wikilinks, embeds, callouts, properties |
| `obsidian-bases` | `.base` files: views, filters, formulas, summaries |
| `json-canvas` | `.canvas` files: nodes, edges, groups, connections |
| `obsidian-cli` | Drive a running Obsidian vault via the `obsidian` CLI |
| `defuddle` | Extract clean markdown from web pages (token-efficient) |

To update: re-vendor from the upstream repo's `skills/` directory.
